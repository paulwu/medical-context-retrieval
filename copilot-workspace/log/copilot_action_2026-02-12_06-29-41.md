## Fix Steps (User Action Required)

These steps must be run from **Windows PowerShell** (not inside WSL):

### Step 1: Restart WSL (most likely fix)
```powershell
wsl --shutdown
```
Then reopen VS Code and rebuild the devcontainer.

### Step 2: If it persists — Check/create `.wslconfig`
Create or edit `C:\Users\pawu\.wslconfig`:
```ini
[wsl2]
memory=8GB
swap=4GB
networkingMode=mirrored
autoProxy=true
```

### Step 3: If it still persists — Reset Docker Desktop
1. Open Docker Desktop → Settings → Resources → WSL Integration
2. Ensure "Ubuntu" is enabled
3. Click "Apply & restart"
4. Alternatively: Docker Desktop → Troubleshoot → "Clean / Purge data"

### Step 4: Nuclear option
```powershell
wsl --shutdown
wsl --unregister Ubuntu
# Reinstall Ubuntu from Microsoft Store
```
