## Why This Keeps Happening

The error **"unexpected end of parent stream"** is NOT a DevContainer config problem. The Docker image builds and starts correctly every time. The issue is:

1. VS Code spawns a WSL2 shell: `wsl -d Ubuntu -e /bin/sh -c cd '...' && /bin/sh`
2. The Dev Containers CLI runs through this shell, creating docker exec sessions
3. **The WSL2 shell terminates spontaneously** (exit code 0) after ~14 seconds
4. All docker exec sessions die → "unexpected end of parent stream"

This is a **WSL2 transport issue** — the pipe between VS Code's Windows process and the WSL2 VM breaks. No Dockerfile or devcontainer.json change can fix the pipe itself.

## Required User Action

**From Windows PowerShell (NOT from WSL):**

```powershell
wsl --shutdown
```

Then:
1. Close VS Code completely
2. Wait 5 seconds
3. Reopen VS Code
4. Reopen the folder in WSL (`Remote-WSL: Open Folder in WSL...`)
5. Rebuild Container (`Dev Containers: Rebuild Container`)

If it still fails after `wsl --shutdown`:
```powershell
# Update WSL kernel
wsl --update

# Check WSL version
wsl --version
```
